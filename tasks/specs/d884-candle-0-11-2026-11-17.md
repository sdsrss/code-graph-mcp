# 2026-11-17 D#884：candle 0.9.2 → 0.11.1，去掉 8 条 zip 审计忽略

状态：**已发布 0.198.0（tag 在 81ef9075，2026-11-18，Release 10/10；main CI 的 Cargo Audit 在不忽略任何条目时通过）**。授权：2026-11-17 用户对授权行 `[AUTH REQUIRED op:candle-core 0.9.2→0.11.1（zip ^9.1.3），并删掉 8 条 audit 忽略 scope:Cargo.toml、Cargo.lock、.github/workflows/ci.yml、tests/hardening.rs]` 回复“该我授权的我授权”，随后“把剩余工作都做了”。

## 为什么

`ci.yml` 忽略 RUSTSEC-2026-0367/0368/0369/0429/0545/0546/0547/0548，都在 zip 7.2.0，只经 candle-core 0.9.2 进来；理由是本工具只加载 safetensors，运行时不执行 zip 代码（`tests/hardening.rs` 的 `AUDIT_IGNORES` 逐条核对理由）。RustSec 库（2026-11-17 读取）：8 条的修复版本都是 zip ≥9.0.0，0548 是 ≥9.0.5。candle-core 0.11.1（crates.io 2026-10-31）要求 zip `^9.1.3`。价值不在运行时暴露（没有），而在以后出新的 zip 公告时不再需要停下来做可达性分析、改 CI 加忽略。

## 改动

- `Cargo.toml`：candle-core / candle-nn / candle-transformers `0.9` → `0.11`；tokenizers `0.22` → `0.23`（candle-core 0.11.1 非可选地依赖 tokenizers `^0.23.1`，同版本避免编进两份）。
- `Cargo.lock`（`cargo update -p candle-core -p candle-nn -p candle-transformers -p tokenizers`）：zip 7.2.0 → 9.6.1，safetensors 0.7.0 → 0.8.0，fancy-regex 0.14.0 → 0.19.2，float8 0.6.1 → 0.7.0，typed-path 0.12.3 → 0.13.0；新增 daachorse、nix 0.32、parking_lot 等。gemm 不变（0.19.0）。
- `ci.yml`：`cargo audit` 不再带 `--ignore`；`tests/hardening.rs` 的 `AUDIT_IGNORES` 清空，守卫机制保留给以后的忽略。
- 源码：`src/embedding/model.rs` 不用改，`cargo check --lib --tests --features embed-model` 无错误无警告。
